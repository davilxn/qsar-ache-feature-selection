# QSAR Modeling of Ionic Liquids for AChE Inhibition

This repository contains the supplementary material associated with the study on the relationship between molecular descriptors of ionic liquids and their inhibitory activity against acetylcholinesterase (AChE), modeled using machine learning techniques in a QSAR framework.

## Overview

The main objective of this work is to:
- Identify relevant molecular descriptors associated with AChE inhibition (logEC50)
- Evaluate the predictive performance of different machine learning models
- Propose a robust feature selection methodology based on multiple complementary criteria

All results reported in the article are reproducible using the materials provided in this repository.
